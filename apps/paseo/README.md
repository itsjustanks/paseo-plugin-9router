# 9Router Paseo plugin

The runtime ID is `agent-link-9router`. Open **9Router** in the Paseo sidebar.

See the [illustrated project README](../../README.md) for installation, the guided walkthrough,
feature map, Astra setup, direct versus routed providers, troubleshooting, and development.

```sh
npm ci
npm run typecheck
npm test
npm run preview:ui
```

The local UI preview uses fictional data and does not connect to a live daemon or provider.
